# Information Panel

Shows extra information about what's currently playing. Which pages
are available depends entirely on what the current track or station
actually has -- an empty page is never shown.

For local music, possible pages are Lyrics (synchronized, embedded or
plain text), Metadata and Codec Information. For Internet Radio,
possible pages are Radio EPG (the current programme plus the next few
upcoming ones, when a station has schedule data), Now Playing, Station
Information and Codec Information.

Press EPG/INFO to switch to this panel from Player (for local music,
by way of the Playlist panel in between; for radio, directly); press
it again to cycle back to Player.

## Keys

- LEFT / RIGHT: switch between the available information pages.
- UP / DOWN: scroll the currently displayed page. On synchronized
  lyrics specifically, UP/DOWN instead nudges the lyrics earlier/
  later relative to the song, in case the timing feels slightly off.
- EPG / INFO: switch to the Player panel.
- HELP: show this help.
- EXIT: stop playback and return to live TV.

## Notes

The panel title always names which kind of information is currently
shown, e.g. "Information: Lyrics LRC" or "Information: Radio EPG".
