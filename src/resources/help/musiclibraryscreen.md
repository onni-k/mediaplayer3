# Music Library

Browse your music collection by artist, album and track, using tags
read from your files rather than folder names.

## Keys

- LEFT / RIGHT: switch between the artists, albums and tracks panels.
- UP / DOWN: move within the active panel.
- CH+ / CH-: jump 10 entries at a time in the active panel (may not
  work on every remote/image).
- OK: play. On the artists panel, plays every track by that artist;
  on the albums panel, plays the whole album; on the tracks panel,
  starts from that track and continues through the rest of the album.
- INFO: search the library by name.
- MENU: open Music Library functions (update the library, or open the
  Main Menu).
- HELP: show this help.
- EXIT: return to the previous screen.

## Notes

Selecting an artist updates the album list to that artist's albums;
selecting an album updates the track list. This is different from
Browser, which follows your folders -- Music Library is built from
the tags stored inside your files, so it works the same way
regardless of how your music is organized on disk.

If the library is empty, use "Update Library" from the menu after
adding music files.
