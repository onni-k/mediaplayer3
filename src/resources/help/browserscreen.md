# Browser

Browse your local storage by folder, exactly like a file manager.

## Keys

- OK: descend into a folder, or play the selected file.
- INFO: open the context menu for the selected entry -- play, add to
  a playlist, import a playlist, or view information, depending on
  what's selected.
- PVR: return to Main Screen.
- MENU: open the Main Menu.
- HELP: show this help.
- EXIT: go up one folder, or leave Browser from the top level.

## Notes

Selecting a playlist file (.m3u/.m3u8) offers to play or import it.
Selecting a folder offers to play every track inside it or add the
whole folder to a playlist.
