# Podcasts

Discover, subscribe to and play podcasts. Three columns: Available
(popular podcasts or search results), Subscribed Podcasts (your own
list) and Episodes (for whichever podcast is currently selected). The
top line shows what the Available column lists and how many podcasts
were found; the previous result is shown again when you come back to
this screen.

## Keys

- LEFT / RIGHT: switch between the Available, Subscribed Podcasts and
  Episodes columns.
- UP / DOWN: move within the active column. Moving within Available
  Podcasts or Subscribed Podcasts updates the Episodes column to
  match.
- CH+ / CH-: jump 15 entries at a time in the active column, stopping
  at the top/bottom of the column.
- OK: open options for the selected item -- in the Available column:
  subscribe/open the podcast, fetch popular podcasts, or search; for
  an episode: play or add it to a playlist.
- YELLOW: fetch popular podcasts or search for podcasts by name (the
  same menu as OK in the Available column).
- BLUE: choose the podcast language -- your receiver's language by
  default, all languages, or one of several others. It applies to
  popular podcasts and to search results.
- GREEN: subscribe to the selected podcast (Available Podcasts
  column), or add the selected episode to a playlist (Episodes
  column) -- without opening the OK menu first.
- RED: unsubscribe from the selected podcast (Subscribed Podcasts
  column).
- EPG / INFO: open this guide.
- MENU: open Settings.
- HELP: show the remote control's own button guide.
- EXIT: return to the previous screen.

## Notes

Podcast search and "Fetch popular podcasts" ask the Podcast Index
service for up to the number of podcasts set in Settings ("Podcast
search limit", default 1000). Because the service cannot search by
language, search results are filtered by the language each podcast
declares, so a language choice can leave fewer results than the limit.

The selected podcast's or episode's description is shown below the
columns.

Subscribed podcasts remain available even when the podcast service is
temporarily unreachable, as long as their episodes were already
loaded at least once.

Episodes are played through the same playback system as local files
and playlists -- MainScreen opens once playback starts.
