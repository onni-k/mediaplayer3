# Developer Tools

Diagnostic information for troubleshooting: runtime status, metadata,
storage, playlists, Internet Radio, logging, system information,
compatibility and build details.

## Keys

- LEFT / RIGHT: switch between pages.
- UP / DOWN: scroll the current page when it doesn't fit on screen.
- RED: export the current log to a file.
- INFO: restate the current page.
- MENU: open the Main Menu.
- HELP: show this help.
- EXIT: return to the previous screen.

## Notes

This screen is intended for troubleshooting. Exporting the log can be
useful when reporting a problem.
