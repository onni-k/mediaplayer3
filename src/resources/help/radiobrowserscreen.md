# Internet Radio

Search and browse Internet Radio stations from RadioBrowser, filtered
by language and region.

## Keys

- LEFT / RIGHT: switch between the stations, language and region
  panels.
- UP / DOWN: move within the active panel.
- CH+ / CH-: jump 15 entries at a time in the active panel, stopping
  at the top/bottom of the list.
- OK: on the Stations panel, opens options for the selected station
  -- play, add to favorites, view station information, update the
  station database, or clear the station list. On the Language/
  Region panel, offers setting the selected entry as Radio's own
  default language/country.
- INFO: search stations by name.
- MENU: open the Main Menu.
- HELP: show this help.
- EXIT: return to the previous screen.

## Notes

Search results update automatically whenever you change the region or
language filter. Your own app language is placed near the top of the
language list to save scrolling through hundreds of entries.
