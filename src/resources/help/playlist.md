# Playlist Panel

Shows the current local playback queue: the previous, current and
next item, the current one highlighted.

Press EPG/INFO to switch to this panel from Player; press it again to
move on to the Information panel.

Only reachable for local music. While listening to Internet Radio,
EPG/INFO cycles between Player and Information only -- switching
favorite lists moved to LEFT/RIGHT in the Player panel instead, since
a live stream can't be seeked anyway. The Previous/Current/Next
display for radio still keeps updating in the background even though
this panel itself isn't reachable for it.

## Keys

- UP / DOWN: move the selection between Previous / Current / Next.
- LEFT / RIGHT: switch to the previous/next local playlist -- the
  same lists Browser offers.
- OK: play the selected entry. It immediately becomes the current
  queue position; playback continues normally through the rest of
  the queue from there.
- EPG / INFO: switch to the Information panel.
- HELP: show this help.
- EXIT: stop playback and return to live TV.

## Notes

The panel title shows which playlist or folder is currently active,
when that information is available.
